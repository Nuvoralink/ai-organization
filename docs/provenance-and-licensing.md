# Provenance and licensing ledger

This private repository distinguishes ownership from technical origin. `registries/artifacts.v1.json` records the origin class of every managed package. User-authored global and project orchestration is maintained here for Nuvoralink's private operational use. Bundled system/plugin packages remain upstream dependencies and are not copied as canonical authorities.

Imported skill rows marked `license: review-required` are intentionally unresolved for redistribution. That label is not a license grant. Until each row has documented permission or an upstream license, the repository must remain private and those packages must not be published, sold, or redistributed outside the authorized organization.

For every future imported artifact, record:

- canonical origin and author/owner;
- imported version, commit, or capture date;
- whether it is user-authored, project-authored, or upstream-owned;
- license or explicit private-use permission;
- update policy and replacement/retirement path.

The validation gate preserves the unresolved status rather than inventing permission. Closing a `review-required` row is a human legal/ownership decision, not an agent inference.
