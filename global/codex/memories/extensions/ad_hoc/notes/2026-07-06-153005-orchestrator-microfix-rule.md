# Orchestrator micro-fix and subagent permission

For Auxara Dialer orchestration, Amin clarified that the main Codex session should stay in orchestrator mode by default, but if a wiring gap or fix is small and fast enough for the orchestrator to do personally, the orchestrator should first say that explicitly so the work reads as an intentional micro-implementation rather than role drift.

Amin also gave standing permission to spawn subagents and use tooling whenever useful without needing a new explicit ask each time. Continue to use subagents/auditors for meaningful implementation or review loops; use personal micro-fixes only when the work is small, low-risk, and announced before editing.
