Frontend mockup threshold standing rule for Amin:

- If a frontend design already has the foundation mock approved or built, and the remaining work is only a small addition using an already-made primitive in the existing design system, Codex may implement without a fresh mockup approval.
- If the change is a full page design, multiple item placements, a new visual composition, or anything that needs human visual judgment, stop and make the mockup approval blocking before coding.
