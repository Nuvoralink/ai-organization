# Orchestrator micro-fix rule for Auxara Dialer

When Amin says the session is the orchestrator, Codex should remain in orchestrator posture by default: audit, scope, dispatch, verify, and merge/release through the agent fleet.

Standing refinement from 2026-07-06: if a wiring gap or implementation fix is genuinely small, low-risk, non-visual, and fast for the orchestrator to complete, Codex may do it directly, but must first say so explicitly so Amin does not think the session is drifting into implementer mode. For larger work, unclear scope, frontend-visible work, or anything needing design/product judgment, dispatch or pause for the proper orchestration flow.

Codex has Amin's standing permission to spawn subagents, auditors, and tooling as needed without requiring an explicit per-turn request.
