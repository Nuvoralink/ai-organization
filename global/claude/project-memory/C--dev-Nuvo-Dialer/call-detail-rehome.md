**SETTLED SHAPE (user-approved 2026-07-12):** ONE composable `<CallDetail>` panel. CANONICAL home = **expand-in-place inside the comms lead-timeline** (`frontend/src/pages/comms/ThreadPane.tsx` — its `TimelineRow` call-event chips are dead-end `<div>`s today; they become expandable). A **thin `/calls/:id` route** is kept ONLY for 3 fallbacks: deep-link/share · **no-lead calls** (inbound-unknown `prospectId:null` + contactless raw-dial keyed to `contact_e164` — no lead timeline to live in) · the **compliance viewer's "prove this one dial."** Both render the SAME panel off ONE data model. Rationale: ADR-BUX-019 ("one engine→one home→per-lead timeline = system-of-record for ALL comms"); the unified `GET /api/prospects/:id/activity` → `LeadActivityResponse` timeline data ALREADY ships; incumbents (Dialpad/Aircall/RingCentral/Kixie/HubSpot) do timeline-row+inline-playback; only Gong/Chorus do a standalone call PAGE, justified by transcript+analytics+coaching = **CoachAI's domain, scoped OUT**. Relates to [[comms-surfaces-architecture]] + [[dialer-workspace-ux-research]].

**SETTLED correction authority (user-approved):** BOOKER corrects OWN call (editable); **MANAGERS/supervisors ALSO correct TEAM calls** (data accuracy) with **distinct provenance** — never re-stamped as if the booker set it (ARC-004 audit honesty). The `dispositionSource` taxonomy (`agent`/`ai_draft_accepted`/`ai_draft_edited`/`system`) has NO manager value → the build ADDS `manager_corrected` + `corrected_by`/`corrected_at` actor attribution + an append-only change audit. Provenance chip is VIEWER-AWARE ("Set by you" only when `agentId===me`; else "Set by <booker>"/"AI draft, accepted"/"Corrected by <manager> · <date>") — fixes reviewer F2 too.

Managers DO have `calls.read_team`+`recordings.read_team`+`dispositions.manage/tenant` (already grant-supported). **F1 fix = grant `agent` `calls.read_self`+`recordings.read_self` + a `self` object-path on `GET /api/calls/:id` + the playback route.** The correction route `/api/calls/:id/disposition` is gated `dispositions.write/self` (booker has it); manager-correct needs the route to ALSO accept `dispositions.manage` + team object-scope + the manager-provenance write.
