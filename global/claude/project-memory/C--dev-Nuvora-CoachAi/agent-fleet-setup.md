The power-user orchestrator/implementer/auditor model (ported + generalized from the Nuvo/Auxara Dialer, which itself carried it from CoachAI originally) was made **global** on 2026-06-14 so every project inherits it.

**Global layer (every project inherits automatically):**
- Agents in `~/.claude/agents/`: `implementer` (Claude-side slice impl; frontend/visual + anything not on Codex), `adversarial-reviewer` (refute-the-done before merge), `security-auditor` (appsec/tenancy). All `model: opus`, project-agnostic (no dialer/CoachAI terms).
- Rules in `~/.claude/rules/`, @-imported from `~/.claude/CLAUDE.md` ("Orchestrator mode & the agent fleet" section): `orchestrator-mode`, `decision-discipline`, `doctrine-loop`, `loop-discipline`, `slice-rigor` (generalized "sprint-rigor"), `test-intent`, `authority-boundary` (generalized: compute-authority = AI-judges/deterministic-validates/guards-non-blocking + action-authority = tiered autonomy). `centralization` was NOT recreated — the global CLAUDE.md gauntlet (Gate 11 / Tokens & scales) already covers it.
- Codex parity: `~/.codex/AGENTS.md` got a mirrored "Orchestrator Mode & the Agent Fleet (Codex ↔ Claude parity)" section (Codex's native always-on file; `~/.codex/rules/` is its command-permission allowlist, NOT a doctrine dir — don't put markdown there).

**CoachAI project layer (`${PROJECT:coachai|backslash}`):**
- 2 domain auditors in `.claude/agents/`: `ai-decision-boundary-auditor` (AI owns meaning / deterministic validates / guards non-blocking / bounded-repair trace truth / paid-AI metering / coaching-line sensitivity source-to-screen / objection-strategy-before-grading) and `source-to-screen-auditor` (authority reaches rendered surface / persisted-derived-state lifecycle / anti-fabrication / coaching-useful-not-graceful-failure / reanalysis-replaces-not-layers).
- Fleet grew after 2026-06-14: `doctrine-drift-auditor`, `test-runner`, `ui-verifier`, `performance-auditor`, `release-verifier`, and (2026-07-08, instantiated from the universal bootstrap templates per the backflow directive; dialer + templates + global rules updated same day) `functionality-parity-auditor` (delivery chain decided→built→wired→called→reachable; NO mechanical wiring gate — CoachAI has no shared endpoint registry, paths inline in `backend/src/app.ts` + `frontend/src/lib/api.ts`, so the manual cross-grep is the floor) + `user-journey-auditor` (ICP's-seat walk; personas verified: booker/rep user per icp-002, trainer/manager beneficiary, agency-owner buyer per icp-001 in `docs/marketing-plan/01-foundations/icp-and-personas/`, internal admin per PRODUCT.md; TWO day-zeros: buyer signup→first coaching + invited-rep accept→first practice line; living inventory at `docs/app-plan/icp-use-case-inventory.md`, created on first run). Cadence lives in `.cursor/rules/slice-rigor.mdc` §5 + CLAUDE.md/AGENTS.md fleet sections. NOTE: `docs/app-plan/decision-log.md` is a docs-repair register only — settled product decisions live in CLAUDE.md §"Coaching Quality Upgrade — Active Work" + `docs/app-plan/implementation/*` plans.
- `.claude/settings.json`: read-only allowlist of CoachAI's REAL scripts (check:ui, check:ui-source, check:ui-continuity, test:doc-code-drift, **gate:test-intent**, build:*, preflight-*) + a `PostToolUse` (Edit|Write) hook → `scripts/claude-posttooluse-gate.mjs`, which runs `check:ui` + `check:ui-continuity` + `check:ui-source` on `frontend/src` edits AND `gate:test-intent --file` on any test-file edit. CORRECTION (proven 2026-06-14): the hook activates **the same session** the settings land, NOT only next session — it fired live and blocked a header-less test write (exit 2).
- **`gate:test-intent` IS wired** (was a follow-up; done 2026-06-14): `scripts/check-test-intent.mjs` (ported from the dialer's `check-test-intent.mjs`, reusing its header-validation logic) enforces the `Proves:`/`Test type:`/`Surface:`/`Authority:`/"What this test proves about the product:" header. Scoping: CoachAI has **299 legacy tests with zero headers**, so enforcement is GRANDFATHERED — default mode checks only files changed vs base; the hook checks the single edited file (ratchet-on-touch); `--all` audits (informational, exit 0); `--all --strict` fails on remaining legacy (full-retrofit milestone). ID shapes accepted: CQ-### (dominant), REQ-AREA-###, G-###, NFR-###, BENCH-*, #issue. npm: `gate:test-intent`, `gate:test-intent:audit`. Bite-tested: bad→exit1, good→exit0, audit→0/296, hook→exit2. The test-file matcher (`*.test|spec.ts|tsx` + basename ending `Regression.ts|mjs`, **suffix-anchored**) is single-sourced in `scripts/lib/test-file-match.mjs`, imported by BOTH the gate and the hook. An adversarial verification workflow (2026-06-14) caught the original unanchored `Regression`-substring regex over-matching 3 non-test helpers (pipelineBRegressionFixtures.ts etc.) + a gate/hook drift hazard — both fixed. (The dialer's identical-looking regex is intentionally unanchored — it has mid-name `*RegressionMatrix.ts` tests — so it was correctly left as-is per "leave dialer as-is".)
- `CLAUDE.md` + `AGENTS.md` each got an "Agent Fleet" pointer section after the always-on rules list.

**Decisions (Amin, 2026-06-14):** global-core + per-project-domain; CoachAI gets 2 (split) auditors not 1; **dialer left as-is** (its `.claude/rules/` + `.codex/rules/` are self-contained duplicates — a candidate to LATER dedupe against the new global layer, not done now); model/cost = the dialer's proven mix (orchestrator = session model; backend/non-visual → Codex CLI + independent Opus auditor; **frontend/coaching-UX always stays on Claude, never Codex**; adversarial + domain + security audits → Opus; scouting → Haiku/built-in Explore).

**Bootstrapping a new project** (so the model spreads): add only (1) project domain auditor(s), (2) `.claude/settings.json` allowlist + PostToolUse gate hook on the repo's real gates, (3) an "Agent fleet" pointer in CLAUDE.md + AGENTS.md, (4) Codex `trust_level = "trusted"`. Do NOT copy the global orchestration rules into the project. Full checklist in `~/.claude/rules/orchestrator-mode.md`.
