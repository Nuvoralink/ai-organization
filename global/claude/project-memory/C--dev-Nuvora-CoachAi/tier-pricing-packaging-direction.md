- **Sonnet "Premium AI" = enterprise-only** (in-deal, priced per deal — matches the existing `premium_models` "enterprise-in-deal" code intent). NOT a self-serve per-seat add-on.
- **Marketing = "unlimited coached calls (fair use)"** — drop the visible 30/100/200 count. Hidden **fair-use cap = 200 analyses/seat/mo** (the no-go-negative backstop; ToS conversation past it, not auto-PAYG).

## UNLIMITED FAIR-USE MODEL (research-backed; Amin approved building it ALL, 2026-06-19)
The adversarial review caught the cap LEAKING in-app ("of 200 used" in the account UsageMeter) + the over-cap deny-then-$2-PAYG copy FAILS the FTC/UK-ASA "unlimited" test (AT&T $60M precedent: undisclosed cap behind a bare "unlimited" = deceptive; ASA: a legit user must incur NO charge AND NO suspension past the threshold). Research workflow → the correct model:
- **Over-cap = KEEP SERVING + a fair-use conversation.** Never deny/throttle/auto-charge at the 200/seat cap; flip an internal `fairUseExceeded` flag → the founder emails "let's right-size". The **COGS ceiling (raised 2.0→5.0, ~3× the cap) is the ONE hard stop**, for genuine runaway/abuse only.
- **DROP PAYG entirely** ($2/analysis ≈ 7× the $0.30 COGS + fails ASA).
- **NO customer usage meter** (Amin: a meter on "unlimited" defeats the purpose). Remove UsageMeter + PaygControls from AccountPage; the customer sees their activity on the EXISTING analytics/coaching surfaces (Progress / This Week / Sessions / Team Insights — verified, removing the meter loses nothing). Build an INTERNAL **admin per-org usage monitor** instead (calls/COGS/margin/fair-use flag per org) — backend data all exists (`getOrgCogsSpentUsd` + `getAnalysisCountGateState`); no per-org admin view today.
- **Disclosure (FTC/ASA):** never a BARE "unlimited" — "Unlimited coached calls* · *fair use" with the qualifier PROXIMATE on the pricing page + a linked Fair-Use Policy page; keep the 200 NUMBER internal; a relational ToS clause ("on the order of a few hundred/seat/mo"). Mockups APPROVED for the meter→activity-stat (now mooted by removal) + the admin monitor table.
