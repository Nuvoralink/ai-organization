# Nuvora Link organization control plane

This generated directory carries vendor-neutral action policy, role registries, task-assurance schemas, shared lifecycle runtime, proof selection, automation specifications, and overlay ownership. Product truth stays in Nuvora Link's ADRs, Nuvo governance, Prisma schema, application source, and tests.

The integration branch is `develop`. The single orchestrator owns dispatch and conclusion; project reviewers are read-only. Visible design approval, production changes, deployments, provider contact, billing, secrets, and destructive actions remain human-gated by the installed universal action policy.
