# New Agent Trying To Improve Fast Audit

## Persona Lens

This persona is early in training or production. They may understand the script intellectually but struggle during live calls. They need specific, practical, confidence-preserving feedback quickly, without a manager having to translate it.

They are eager but uncertain. Their success state is: upload a call, see one clear next-call focus, understand what they said and why it was weak, practice an approved replacement line, see progress across calls, and feel guided rather than judged.

## Product Truths

- Rep view should be simpler than manager view.
- The first screen should show one primary next-call focus, not a manager-style diagnostic dump.
- Feedback should be short, plain-language, action-oriented, and tied to exact call moments.
- The rep should see approved or manager-allowed lines only.
- In Strict Mode, the rep must never see unapproved AI-generated lines.
- Scores must explain why points were lost in language a new agent can understand.
- The improvement plan should include one drill, one practice line, and progress toward the next skill.
- Positive reinforcement matters; the product should show what the rep did well without hiding required fixes.
- Required fixes must be clearly distinct from optional improvement tips.

## Audit Workflow

1. Start from the ideal rep outcome: know what to fix first, what to say next time, and how to practice before the next call.
2. Inspect rep-visible surfaces separately from manager/owner surfaces: routes, API filtering, DTO mapping, permissions, copy, score explanations, drill generation, and UI hierarchy.
3. Verify that manager-only diagnostics, unapproved AI lines, and material-intelligence notes are hidden or reframed before reaching the rep.
4. Check whether next-call focus and drills use rep-actionable coaching lane predicates, not raw NO/PARTIAL checklist rows.
5. Trace replacement-line authority from source materials through persistence, API, and UI labels.
6. Treat overwhelm, contradictory AI/manager guidance, unclear score reasons, and harsh feedback without practice steps as product bugs.
7. Prefer root-cause fixes in filtering, lane helpers, permissions, DTOs, prompt output, or shared presentation helpers over local copy masking.

## Audit Questions

- Can the agent understand what to fix in under 60 seconds?
- Can the agent see one clear next-call focus?
- Can the agent practice an approved line immediately?
- Can the agent tell whether a line is approved by the team or generated by AI?
- Can the agent understand why they lost points?
- Can the agent see progress after uploading future calls?
- Can the agent avoid seeing manager-only AI suggestions in Strict Mode?
- Can the agent use the feedback without needing a manager to translate it?
- Does the product help the agent feel guided rather than judged?

## Output Style

For audits, lead with findings ordered by learning, trust, and confidence risk. Include file and line references when reviewing code. For each material finding, state the new-agent impact, likely root cause, and the durable fix.
