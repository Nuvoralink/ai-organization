## Audit checklist — verify each against actual code, citing `file:line`
1. **AI owns the meaning; deterministic code validates.** The sales/coaching semantic judgment (real objection? booking moment? right speaker? does evidence support this claim?) is made by AI from compact grounded evidence. Deterministic code only validates grounding, schema/contract, policy/safety, speaker/source authority, provenance, persistence — it does not *compute* the meaning. Deterministic meaning-logic without a nearby `SEMANTIC_DETERMINISM_ALLOW:` comment (+ a scope-proving regression) is a **blocking** finding.
2. **Guards are non-blocking signals, never authoritative.** A schema-valid AI verdict reaches the final output. Grounding/speaker/time-window/confidence checks may attach a confidence discount or an `unverified`/low-trust provenance flag — they must **never** reject, discard, override, substitute, trigger a fallback that overwrites the verdict, or trip a `limited`/degraded state on their own. Hunt for window gates and confidence-floor rejections on AI meaning — those are the canonical regression (one upstream slip + an authoritative guard → wrong verdict AND wrong honesty state). Only schema + security/policy are hard gates.
3. **Teach intent, not keywords** where meaning turns on look-alikes/paraphrase/indirect phrasing/who-is-driving/booking-moment (the ROLE-INTENT + CQ-007 pattern). A prompt deciding meaning off surface keywords, or a hardcoded phrase/objection taxonomy as the primary intelligence, is a finding.
4. **Validation feeds back into generation.** A failed field triggers a bounded retry naming exactly what failed + the correct authority, sends back only the failed fields, and merges the repaired field into the previously-validated-good payload. The validator must not silently rewrite output. **Bounded-repair trace truth:** a second-pass repair that still fails traces `rejected`, not `repaired` (canonical: `semanticJudgment.ts`) — trace, product output, warnings, telemetry tell one story.
5. **AI-output bugs are fixed at the AI contract.** When the visible bug is AI generating the wrong line/decision/context-use, the primary fix is source authority / prompt / schema / decision matrix / examples+counterexamples / grounding / bounded retry — **not** a forbidden-phrase list or deterministic rewrite. Deterministic code may still validate schema/grounding/provenance/safety/visibility as a backstop, never as the intelligence layer.
6. **Coaching-line sensitivity is source-to-screen authority.** Effective sensitivity flows through Prompt A input → repair prompts → `parseMachineCoachingFooter` → persisted structured coaching provenance → Call Review DTO projection → generated-drill DTOs → frontend line visibility. `strict` hides suggested/generated examples; `recommended` shows only grounded generated spoken examples (no gate reasons); gate-reason/failed-repair lines fail closed. A broken link in that chain is a finding.
7. **Objection handling decides strategy before grading.** The matrix first asks what *should* have happened to move toward a cemented booked appointment (recovery / light-timing continuation / legitimate callback fallback / controlled booking / cementing) — only then judges callback specificity, replacement/drill lines, scoring, ranking, copy. Grading the path the rep happened to choose, or turning observed objection phrases into deterministic strategy rules, is a finding.
8. **Paid-AI metering invariant.** Every OpenAI/Gemini/Groq/paid call goes through the metered adapters with stable stage/role/capability/provider/model/tokens/cost; no raw prompt/transcript/audio/customer/secret metadata in usage rows; model/tier routing centralized in `backend/src/lib/aiModelPolicy.ts` + `backend/src/lib/aiTierPolicy.ts`. An unmetered paid call or leaked metadata is a **blocking** finding.
9. **Content-correctness gate at WRITE time** for authoritative artifacts (golden seed, baseline DTO, scoring snapshot, calibration output, regression fixture): the gate checks the artifact's *content* satisfies source-of-truth invariants (analyzability state, semantic-judgment status, role-confidence aggregate, integrity status, no pipeline rejection reasons) — not just "ran clean + file written." Per-utterance/stage model confidence is not authoritative downstream (the model can say `high` and be wrong).
10. **Coaching quality beats graceful failure.** If transcript/material evidence exists and the output is blank/generic/low-leverage/missing a usable practice move, that is a product defect to repair upstream (source / AI contract / validation-repair / persistence / DTO / mapper / UI), not an acceptable honest-fallback.
